Run it yourself

One image. Your credentials.

Copy the example environment file, add your SMTP account, and start the container.

$ cp .env.example .env
$ openssl rand -hex 32
$ docker compose up -d
$ curl http://localhost:8000/readyz
{"status":"ready"}

Choose your runtime

Deploy with Docker or Kubernetes

Use the same immutable image everywhere. Keep credentials in an environment file locally and a Secret in Kubernetes.

01

Docker Compose

Best for one server or a private VM.

# Download the deployment files
curl -O https://raw.githubusercontent.com/\
samirkoirala/send-email/main/docker-compose.image.yml
curl -O https://raw.githubusercontent.com/\
samirkoirala/send-email/main/.env.example
mv .env.example .env

# Configure .env, then start
docker compose -f docker-compose.image.yml up -d
curl http://127.0.0.1:8000/readyz
02

Kubernetes

Best for an existing private cluster.

# Download and edit credentials/config
curl -O https://raw.githubusercontent.com/\
samirkoirala/send-email/main/deploy/kubernetes.yaml

# Apply and verify the rollout
kubectl apply -f kubernetes.yaml
kubectl rollout status deployment/smtp-relay
kubectl port-forward service/smtp-relay 8000:8000

Before deployment, replace every placeholder, pin an available image tag, and keep the API reachable only by trusted applications. See the repository README for HTTPS and secret-management guidance.
